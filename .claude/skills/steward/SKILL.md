# PR Steward rules: HH-Locations

This repo holds the CSS and JS that are pasted by hand into Stockist (the store locator on hhbagels.com). It has no build and no CI.

- Keep changes small and scoped to the bug or the review comment.
- The README documents what's live. When you change the CSS or JS, update the matching README section in the same PR.
- Don't push to `main`.
